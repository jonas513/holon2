## Design audit — huidige pijnpunten

### Globaal
- **Stijl**: Web 2.0 uit 2012 (globe-logo, gradient-knoppen, foto-slider, sidebar nav)
- **Geen coherent design systeem**: Masterclass-sectie heeft een volledig andere stijl (moderne bubbels, echte foto's, SVG-iconen) vs. de rest van de site
- **Mobiel**: Geen evident mobile-first design
- **Typografie**: Flat schaal, weinig hiërarchie tussen heading levels
- **Kleur**: Teal/cyaan brand accent, rest neutraal — werkt maar is gedateerd

### Per pagina
- **Home**: 7-slide carousel = gevecht om aandacht, geen duidelijke primaire CTA. 4 USP-blokken onderaan zijn te klein.
- **SAP-CO**: Puur tekst + sidebar, geen visuele structuur of sociale bewijslast
- **Masterclass**: Relatief modern maar visueel niet geïntegreerd met de rest
- **Audit**: Meest minimale pagina — bijna geen content, geen foto
- **P&L**: Tekst-dominant, goede inhoud maar moeilijk te scannen
- **Referenties**: Grid van logo's werkt maar is niet overtuigend gepresenteerd

## Redesign plan — fasen

### Fase 1: Context & strategie (1 sessie)
- [ ] PRODUCT.md aanmaken (run `/impeccable teach`)
- [ ] Doelgroep definiëren: wie bezoekt holon.be? (controllers, SAP-managers, HR bij grote bedrijven)
- [ ] Tone of voice vastleggen: expert maar toegankelijk, Belgisch-nuchter
- [ ] Primaire CTA per pagina kiezen
- [ ] Design register bepalen: brand (marketing) vs product (app) → **brand**
- [ ] Kleurstrategie kiezen: teal behouden of vernieuwen?

### Fase 2: Design systeem (1-2 sessies)
- [ ] DESIGN.md aanmaken (run `/impeccable document` of manueel opbouwen)
- [ ] Kleurpalette OKLCH definiëren (teal-gebaseerd, geen #000/#fff)
- [ ] Typografie kiezen: 1-2 fonts, duidelijke schaal (min. 1.25 ratio)
- [ ] Component bibliotheek schetsen: nav, hero, card, CTA, form, footer
- [ ] Logo evalueren: globe-logo behouden of moderniseren?

### Fase 3: Homepage (1-2 sessies)
- [ ] Slider vervangen door statische hero met 1 sterke boodschap
- [ ] 4 diensten overzichtelijk presenteren (geen identieke kaartjes)
- [ ] Klantlogo's prominent tonen als sociale bewijslast
- [ ] Nieuwsbrief-inschrijving integreren maar niet dominant
- [ ] `/impeccable craft homepage`

### Fase 4: Kernpagina's (2-3 sessies)
- [ ] SAP-CO Consultancy — visuele structuur + foto's
- [ ] SAP-CO Masterclass — integreren in nieuw design systeem
- [ ] SAP-CO Audit — foto toevoegen, inhoud visueel versterken
- [ ] P&L by Destination — management reporting visueel maken

### Fase 5: Ondersteunende pagina's (1-2 sessies)
- [ ] Referenties — logo grid vernieuwen, testimonials toevoegen
- [ ] Contact — formulier + kaart + persoonlijke touch (Mark's foto)
- [ ] Kom ons team versterken — werving aantrekkelijker maken
- [ ] Download whitepaper — lead-gen pagina optimaliseren

### Fase 6: QA & afwerking (1 sessie)
- [ ] Responsief testen (mobiel, tablet, desktop)
- [ ] Toegankelijkheid (alt-tekst, contrast, focus states)
- [ ] Performance (afbeeldingen geoptimaliseerd)
- [ ] `/impeccable audit` per pagina
- [ ] `/impeccable polish` finale pass
